Page 1 – Activity 1 + Core Thinking

Design Factors

  • Use → layout, size, services
  • Spatial → rooms, circulation, flexibility
  • Sustainability → EPC, CO₂, renewables, water
  • Access → Part M, inclusive design
  • Aesthetic → planning, context, sympathetic design
  • MMC → modular / SIPs / prefab = faster, less waste

Constraints

  • Time → PoW, sequencing, critical path → MMC speeds build
  • Cost → BoQs, QS, contingency, prelims → affects spec / finishes / value engineering
  • Ground → surveys, contamination, water → affects foundations / cost / time
  • Site → size, shape, access, orientation → affects layout / buildability
  • Planning → height, materials, conservation, privacy → redesign risk / delays
  • Logistics → deliveries, storage, crane access → JIT / modular

Extra Factors

  • Acoustics → insulation / zoning / room positioning
  • H&S → CDM / HASAWA / site setup / safe access
  • Environmental → TPOs / protected species / remediation
  • Services → drainage / utilities / M&E provision

Risk

  • Ground risk → delays / cost overruns
  • Planning risk → refusal / redesign
  • Programme risk → fines / liquidated damages
  • Cost risk → inflation / changes / errors
  • Mitigate → surveys / planning ahead / contingency / sequencing

Comparison Language

  • Modular → best for time / logistics
  • Steel → best for speed / open spans
  • Concrete → best for fire / durability / acoustics
  • Traditional → best for sympathetic aesthetics
Use: better than / however / because

Quick Links

Activity 3 – Size, Form, Construction

Size

  • Based on spatial requirements
  • Limited by site / planning / budget

Form

  • Orientation for light / energy
  • Shape = function + context
  • Sympathetic to surroundings

Foundations

  • Pad → good ground / low loads
  • Raft → weaker ground / spreads load
  • Piled → poor ground / heavy loads

Superstructure

  • Brick & block
  • Steel frame
  • Concrete frame
  • SIPs
  • Modular

Roof

  • Flat / sedum → sustainable, insulation, biodiversity
  • Pitched → traditional appearance

Justification Framework

  • Suitability
  • Cost
  • Time
  • Sustainability
  • Buildability
  • Aesthetic
  • Maintenance

Buildability / Maintenance / Services

  • Buildability → access / labour / material availability
  • Maintenance → durability / repairs / replacements
  • Services → heating / ventilation / drainage / M&E / internet

Material Triggers

  • SIPs → fast, insulated, low waste
  • Steel → strong, fast, needs fire protection
  • Concrete → durable, fire resistant, high carbon
  • Modular → off-site, quick, fewer deliveries

Fire

  • Means of escape
  • Compartmentation
  • Fire resistance
  • Travel distance
